StickItUp - Wallpaper App

StickItUp is a modern wallpaper app that lets users browse and set high-quality wallpapers with ease. The app features a smooth and interactive UI, optimized scrolling, and the ability to set wallpapers for the home screen, lock screen, or both.

Features

📌 High-Quality Wallpapers - Browse a collection of stunning wallpapers.

*⚡ Optimized Scrolling - Uses compressed previews for a smooth experience.(Still not done work in progress.... u may have lag)

📱 Set Wallpapers Easily - Apply wallpapers to home screen, lock screen, or both.

🌙 Dark Mode Support - The app follows the system theme.

🎨 Modern UI - A clean and user-friendly interface.

Installation

📥 Download APK

You can download the latest version of StickItUp from the Releases section.

🔧 Build From Source

To build the app from source, follow these steps:

Clone this repository:

git clone https://github.com/YOUR_GITHUB_USERNAME/StickItUp.git
cd StickItUp

Open the project in Android Studio.

Build and run the app on an emulator or real device.

How to Contribute

Contributions are welcome! Feel free to fork this repository and submit a pull request with improvements.

Fork the repo.

Create a new branch (feature-new-feature).

Commit changes and push to your branch.

Submit a Pull Request.

Updating the App

When adding new wallpapers:

Place the new images in the drawable/ folder.

Ensure that their filenames follow the wallpaper_ prefix.

The app dynamically loads wallpapers, so no additional code changes are needed!
